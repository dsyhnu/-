## LLM 作为进化优化器应用于分子优化任务，具有较强的创新性和应用价值。
1.2 主要工作任务  
本项目主要任务包括以下几个方面：  
1. 文献调研与理论学习：调研 LLM 在进化算法中的应用，特别是在分子优
化领域的应用进展，学习相关的优化方法和技术。  
2. LLM 模型选择与实验平台搭建：选择适合的 LLM 模型（如 OpenAI 的 GPT
系列或 Anthropic 的 Claude 系列），并搭建实验平台，准备分子优化所需的标准  
数据集。  
3. 进化优化框架设计与实现：基于传统进化算法框架（包括选择、交叉、
变异、评估和更新种群），将交叉和变异步骤交给 LLM 进行操作，实现 LLM 辅助  
的进化优化框架。  
4. 实验与数据分析：通过实验评估 LLM 在分子优化中的表现，并与传统进
化算法进行对比分析，评估其在解的质量、收敛速度及计算效率等方面的优势。  
5. 成果总结与论文撰写：整理研究成果，撰写毕业设计报告，形成学术论
文，探讨 LLM 在进化优化中的应用潜力与未来方向。  
1.3 研究内容  
1. LLM 与分子优化的结合：通过 LLM 生成分子结构的变异和交叉操作，探
索其在优化任务中的效果。  
2. 优化算法的改进与应用：在传统进化算法框架下，替换交叉与变异步骤，
采用 LLM 来生成新的分子结构，进行优化。  
3. 性能对比与优化：分析所提方法与传统方法在多个标准数据集上的比
较，评估其性能，包括优化效率、质量和计算资源消耗。  
二、任务目的  
本研究旨在探讨 LLM 在进化算法中应用的可行性与优势，尤其是在分子优化任务  
中的表现。通过将 LLM 集成到进化算法中，不仅可以提升优化效率，还能进一步  
扩展 LLM 在科学计算和分子设计中的应用范围。具体目标如下：  
1. 提高分子优化算法的精度与效率，减少依赖人工设计的规则。
2. 探索大语言模型在分子优化中的应用，推动其在化学、药物研发等领域
的应用。  
3. 培养学生在人工智能与分子设计方面的实践能力，锻炼其算法创新与实
验设计的能力。  
三、任务要求  
3.1 基础知识要求  
1. 深度学习基础：学生应具备扎实的深度学习基础，了解 LLM 的基本原理
及应用，熟悉其在优化中的潜力。  
2. 分子结构与化学知识：学生应掌握分子结构的基本知识，能够使用相关
工具和方法表示分子结构，如 SMILES、分子图等。  
3. 进化算法基础：熟悉传统进化算法的基本原理及其在优化问题中的应
用，了解交叉、变异、选择等步骤。  

## 3.2 技术与工具要求
1. 模型框架与实验平台：学生需要使用适合的 LLM 模型（如 GPT、DeepSeek
等），并搭建相关的实验平台，能够进行算法的开发和实验验证。  
2. 编程能力：掌握至少一门编程语言（如 Python），熟悉深度学习框架（如
PyTorch、TensorFlow 等），能够进行模型训练与优化。  
3. 实验设计与数据分析：能够设计合理的实验方案，进行数据收集、统计
分析，并总结实验结果。

1. 文献调研与总结：深入查阅与分子优化、进化算法、LLM 应用相关的研
