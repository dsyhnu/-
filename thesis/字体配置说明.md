# 论文字体配置说明

## 当前配置

### 使用的编译引擎
- **xelatex** - 支持系统字体和TrueType/OpenType字体

### 字体配置
在 `main.tex` 中使用 ctex 包的默认字体集：
```latex
\usepackage[UTF8]{ctex}  % 中文支持，使用默认字体集
```

### 字号设置
按照湖南大学毕业论文规范：

| 元素 | 规范要求 | 当前设置 |
|------|---------|---------|
| 论文题目 | 小2号黑体 | ✓ 已配置 |
| 章标题 | 3号黑体 | ✓ 已配置 (\sizeThree + \heiti) |
| 节标题 | 小4号黑体 | ✓ 已配置 (\sizeFourl + \heiti) |
| 条标题 | 小4号黑体 | ✓ 已配置 (\sizeFourl + \heiti) |
| 正文 | 小4号宋体 | ✓ 已配置 (12pt + ctex默认宋体) |
| 页码 | 5号宋体 | ✓ 已配置 (\zihao{-5}) |
| 数字和字母 | Times New Roman | ✓ xelatex自动处理 |

### 行距
- 规范要求：1.5倍行距
- 当前设置：`\linespread{1.625}` （接近1.5倍）
- 正文字号：12pt，行距19.5pt

## 字体说明

### ctex默认字体集
ctex包会根据操作系统自动选择合适的中文字体：
- **Linux**: 通常使用 Fandol 字体集（包括宋体、黑体、仿宋、楷体）
- **Windows**: 使用系统自带的宋体、黑体等
- **macOS**: 使用华文系列字体

### 当前系统字体
在您的Ubuntu系统上，ctex使用的是：
- 宋体：FandolSong 或 Noto Serif CJK SC
- 黑体：FandolHei 或 Noto Sans CJK SC
- 这些字体都符合学术规范要求

## 编译方法

```bash
cd thesis
xelatex -interaction=nonstopmode main.tex
xelatex -interaction=nonstopmode main.tex  # 运行两次确保引用正确
```

或使用编译脚本：
```bash
./compile_thesis.sh
```

## 注意事项

1. **必须使用xelatex编译**，不能使用pdflatex
2. ctex包会自动处理中英文混排的字体切换
3. 英文和数字会自动使用Times New Roman字体
4. 如果需要更换字体，可以修改 `\usepackage[UTF8]{ctex}` 的配置参数
